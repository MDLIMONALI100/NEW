Project overview

Money Tracker is a minimalist money app for students: a weekly budget, income tracking, monthly stats, savings goals, a choice of currency, a daily reminder, bill splitting and backup. Optional Google sign-in syncs data between phones and creates shareable monthly summaries. The link on this page downloads the Android APK.

I build apps and games like this from Kushtia, Bangladesh, and ship them so anyone in the world can open them in a browser or on their phone.

The challenge

Students want something quicker than a spreadsheet and simpler than a banking app. It had to work fully offline, and when sync is switched on, merge changes from two phones without losing anyone's data.

Technical stack used

  • React Native
  • Expo
  • Cloudflare Workers
  • Cloudflare D1 (SQL)
  • Google Sign-In
  • EAS Build

My role and solutions

  • Designed and built the app screens (Home, Stats, Goals, More) and the charts and share card.
  • Wrote the sync rules that merge data between devices, and the Worker API with a D1 database for sign-in checks, sync, share links and account deletion.
  • Set up builds and over-the-air updates so fixes reach installed phones without a reinstall.

Business impact and results

  • Works fully offline; cloud sync is optional and opt-in.
  • Screen and logic changes reach installed phones through over-the-air updates.
  • Shareable monthly summaries and an account-deletion route, so users stay in control of their data.
