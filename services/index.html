Services

Web development services in Kushtia, Bangladesh

Shopify stores, WordPress and WooCommerce sites, hand-coded websites and full-stack web apps, built by one developer you can talk to directly. I work with businesses in Kushtia and across Bangladesh, and with clients overseas.

What I can build for you

01

Shopify Store Development

A Shopify store that looks like your brand, loads quickly on a phone and makes it easy to buy. I customise themes with Liquid, CSS and JavaScript, set up collections and products, and keep the checkout short.

  • Theme customisation and branding
  • Collections, products and navigation set-up
  • Mobile-first layout and fast loading
  • Handover so you can manage orders yourself
02

WordPress & WooCommerce Development

Business websites and online shops you can edit yourself. I build with WordPress, Elementor and WooCommerce, add custom touches such as slide-out carts, and tune everything for speed and search engines.

  • Business sites, landing pages and blogs
  • WooCommerce stores with custom cart and checkout touches
  • Elementor layouts you can edit without code
  • Redesigns and take-overs of existing WordPress sites
03

Custom-Coded Websites

When a template is not enough, I write the site by hand. No page-builder weight, clean semantic HTML, strong accessibility and top performance scores, hosted cheaply on a global network.

  • Hand-written HTML, CSS and JavaScript
  • Accessible, semantic and search-friendly markup
  • Static hosting on GitHub Pages or Cloudflare
  • Animations and interactions that stay fast
04

Full-Stack Web Apps

For products that need accounts, data and an admin panel. I build front end, API and database together, for example the Streetwear store in my portfolio, with a 200-product catalog and a no-code admin.

  • Next.js and React front ends
  • Node.js and Express APIs on Cloudflare Workers
  • SQL (D1, Supabase) and MongoDB databases
  • Admin panels so non-developers can manage content
